# VideoDownLoader

Небольшое Windows-приложение для загрузки доступных видео и прямых трансляций.
Программа не реализует обход DRM и предназначена только для контента, который
пользователь имеет право сохранять.

## Возможности

- предварительный анализ ссылки с названием, обложкой, длительностью, автором и доступными форматами;
- проверка признаков DRM до добавления задания в очередь;
- последовательная очередь: ошибка одного задания не останавливает остальные;
- выбор автоматического качества или конкретного формата, контейнеры MKV/MP4/WebM;
- сохранение аудио в MP3, M4A или Opus;
- загрузка и встраивание субтитров, метаданных, глав и обложки;
- авторизация через cookies Chrome, Edge, Firefox или Brave без хранения cookies приложением;
- запись активных трансляций и опциональная попытка начать с начала DVR;
- плейлисты, повторные попытки, продолжение незавершённой загрузки;
- журнал, прогресс, отмена и повтор задания;
- история последних 200 результатов и сохранение пользовательских настроек;
- проверка свободного места и запрет сна Windows во время работы очереди;
- автоматическая проверка обновлений `yt-dlp`, FFmpeg и Deno при каждом запуске;
- установка официальных сборок `yt-dlp`, FFmpeg и Deno с проверкой опубликованных SHA-256;
- автоматическое обновление `yt-dlp` и Deno с одной повторной попыткой после устранимых сбоев YouTube;
- классификация 403, bot-check, PO Token, авторизации, rate limit, DRM, сетевых и дисковых ошибок;
- переключение между каналами `nightly` и `stable` (`nightly` рекомендуется для YouTube);
- опциональное подключение внешнего совместимого PO Token provider с проверкой endpoint `/ping`;
- копирование очищенной диагностики без подписей, токенов и IP-параметров медиассылок.

## Запуск

Требуется Windows 10/11 и .NET 8 Desktop Runtime. Для разработки подойдёт
Visual Studio 2022 или установленный .NET 8 SDK.

```powershell
dotnet run --project .\src\VideoDownLoader\VideoDownLoader.csproj
```

При первом запуске:

1. Нажмите **Установить инструменты**.
2. Вставьте ссылку на видео или эфир и нажмите **Проверить ссылку**.
3. Убедитесь, что источник доступен, затем выберите формат и параметры.
4. Нажмите **Добавить в очередь**, после чего — **Запустить очередь**.

Инструменты (`yt-dlp`, FFmpeg и Deno для JavaScript-проверок YouTube) сохраняются в `%LOCALAPPDATA%\VideoDownLoader\tools` и не
добавляются в системный `PATH`.

### Устойчивость YouTube

По умолчанию приложение использует официальный nightly-канал `yt-dlp`, автоматически
обновляет YouTube-компоненты при запуске и делает не более одной повторной попытки
после ошибки, которую может исправить обновление. Для снижения риска rate limit между
служебными запросами к источнику добавлена небольшая пауза. Для временных сетевых
разрывов используются до 20 внутренних попыток с экспоненциальной задержкой до
20 секунд; после их исчерпания приложение один раз перезапускает процесс и продолжает
существующий `.part`-файл.

PO Token provider выключен по умолчанию. Если YouTube действительно требует Proof of
Origin, отдельно запустите совместимый HTTP provider и установите его плагин для
`yt-dlp` в `%LOCALAPPDATA%\VideoDownLoader\tools\plugins` либо в стандартный каталог
плагинов `yt-dlp`. Затем включите provider в приложении и проверьте его кнопкой
**Проверить**. Приложение не скачивает и не запускает сторонний provider без явного
решения пользователя.

## Сборка

```powershell
dotnet build .\VideoDownLoader.sln --configuration Release
```

Собранное приложение находится в
`src\VideoDownLoader\bin\Release\net8.0-windows`.

## Ограничения

Доступность форматов зависит от источника. Закрытый, платный или требующий
авторизации контент без подходящей сессии может быть недоступен. Опция DVR
работает только тогда, когда сам источник отдаёт предыдущие сегменты эфира.

Проверка DRM использует признаки, которые сообщает извлекатель `yt-dlp`, и
известные сообщения об ошибках источников. Приложение блокирует загрузку, когда
обнаружена DRM-защита без обычного доступного формата. Оно не получает ключи,
не расшифровывает DRM и не пытается обходить ограничения. Обычный HLS с ключом,
который источник сам предоставляет проигрывателю, не считается DRM автоматически.
