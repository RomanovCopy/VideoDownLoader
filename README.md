# VideoDownLoader

Небольшое Windows-приложение для загрузки доступных видео и прямых трансляций.
Программа не реализует обход DRM и предназначена только для контента, который
пользователь имеет право сохранять.

## Возможности прототипа

- загрузка по ссылке на страницу, HLS (`.m3u8`) или DASH (`.mpd`);
- выбор лучшего качества либо ограничение до 1080p/720p;
- сохранение только аудио в MP3;
- объединение раздельных видео- и аудиодорожек в MKV или MP4;
- запись активных трансляций и опциональная попытка начать с начала DVR;
- плейлисты, повторные попытки, продолжение незавершённой загрузки;
- журнал, прогресс и отмена операции;
- автоматическая установка официальных сборок `yt-dlp` и FFmpeg.

## Запуск

Требуется Windows 10/11 и .NET 8 Desktop Runtime. Для разработки подойдёт
Visual Studio 2022 или установленный .NET 8 SDK.

```powershell
dotnet run --project .\src\VideoDownLoader\VideoDownLoader.csproj
```

При первом запуске:

1. Нажмите **Установить инструменты**.
2. Вставьте ссылку на видео или эфир.
3. Выберите папку и качество.
4. Нажмите **Загрузить**.

Инструменты сохраняются в `%LOCALAPPDATA%\VideoDownLoader\tools` и не
добавляются в системный `PATH`.

## Сборка

```powershell
dotnet build .\VideoDownLoader.sln --configuration Release
```

Собранное приложение находится в
`src\VideoDownLoader\bin\Release\net8.0-windows`.

## Ограничения

Доступность форматов зависит от источника. Закрытый, платный или требующий
авторизации контент без подходящей сессии может быть недоступен. Опция DVR
работает только тогда, когда сам источник отдаёт предыдущие сегменты эфира.
